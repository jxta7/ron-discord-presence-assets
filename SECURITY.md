# Security

- Keep the repository limited to static PNG, JSON, and Markdown files.
- Never add `client_secret`, bot tokens, OAuth access/refresh tokens, webhook secrets, cookies, or personal credentials.
- Do not add auto-updaters or code that downloads and executes remote scripts.
- Pin production image URLs to an immutable Git commit SHA.
- Review file hashes in `checksums.sha256.json` before publishing a release.
