# Ready or Not Discord Presence Assets

Static image assets prepared for the Ready or Not Discord Rich Presence mod.

## Layout
- `maps/` — one mission image per mission
- `hq/station.png` — LSPD / station image
- `icons/` — seven weapon-class icons (`AR`, `BR`, `PDW`, `SMG`, `SG`, `GL`, `LL`)
- `manifest.json` — stable mapping used by the mod
- `checksums.sha256.json` — integrity hashes

## Security
This repository should contain only static images and metadata. Do not commit Discord client secrets, bot tokens, OAuth tokens, webhooks, cookies, API keys, or executable scripts. The Discord Application ID is a public identifier and does not need to be treated as a secret.

For releases, prefer immutable CDN URLs pinned to a Git commit SHA instead of URLs tracking `main`.
